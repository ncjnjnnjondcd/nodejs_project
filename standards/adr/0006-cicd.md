## Context and Problem
Знайти інструмент для автоматичної перевірки коду та його доставки

## Decision Drivers
* Вбудований в гіт 
* Можна виористати в github

## Considered Options
* **Option 1:** [GitHub Actions]
* **Option 2:** [GitLab CI/CD]

### Option 1: [Варіант 1]
* простий, конфігурація живе прямо в репозиторії, безкоштовний
* привязка до github

### Option 2: [Варіант 2]
* гнучкий yaml - підтримує складні сценарії, легка підтримка self-hosted
* складність, привязка до GitLab

## Decision Outcome
Chosen option: **[GitHub Actions]**, весь проєкт вже на github, не хочу переносии його на gitlab

## Consequences
* Good: є готові рішення для пайплайнів, швидкий початок
* Bad: привязка до github
