Код відповідає режиму суворої типізації TypeScript
Відсутні помилки компіляції типів (npm run typecheck)
Відсутні помилки та критичні попередження лінтера (npm run lint)
Код відформатовано відповідно до правил Prettier (npm run format:check)
Додано git-hook на commit/push 


Проєкт стабільно збирається без помилок компіляції (npm run build)
Написані та успішно проходять тести (npm run test)
